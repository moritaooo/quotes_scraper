# Quotes Scraper（名言スクレイパー）

このプロジェクトは、「Quotes to Scrape」ウェブサイトからインスピレーショナルな名言をスクレイピングし、CSV ファイルに保存する Python スクリプトです。

## 機能

- 名言、著者、タグをウェブサイトからスクレイピングします。
- データを CSV ファイルとして保存しますので、簡単にアクセスして分析できます。

## 必要な環境

このスクレイパーを使用するためには、Python 3.x のインストールが必要です。また、以下の Python ライブラリも必要です。

- requests
- BeautifulSoup4
- pandas
